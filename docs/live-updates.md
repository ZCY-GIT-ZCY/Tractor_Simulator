# 保留牌局的前后端更新

应用通过常驻 HTTP 网关接入，游戏进程运行在独立回环端口。前端、规则引擎、AI 和 HTTP 后端可一起替换；网关端口、游戏实例 ID、浏览器凭据和 Cloudflare 连接保持不变。切换期间请求短暂排队，通常数秒，页面不退出牌桌。新界面在刷新页面后生效，已有页面继续使用兼容的 API，并提示服务已更新。

此机制不依赖浏览器重发操作。已经进入旧后端的请求先完成；排队的请求只交给新后端一次。更新期间不计入六秒亮主等待、离线超时、结算确认等待或回放耗时。多人摸牌的前端定时器也会等待原请求返回。

## 首次启用

旧版直接运行的服务没有完整房间导出入口，不能将其内存安全搬迁到网关。**首次启用必须等现有牌局结束，再切换一次游戏服务**。已完成回放继续保留。`update_live.py` 检测到旧服务会拒绝更新，并且不会重启任何进程。

Windows / 本地试用（请先关闭原来的游戏服务）：

```powershell
cd D:\Research\Tractor\Simulator
python -m tractor_sim.live --host 127.0.0.1 --port 8765
```

Linux 已有独立隧道时，首次只切换游戏服务：

```bash
cd ~/tractor
python3 tools/install_services.py --live --game-only --host 0.0.0.0
```

这条命令会重启 `tractor.service`，不会改写或重启 `tractor-tunnel.service`。首次游戏实例 ID 改变后，现有隧道会重新验证同一入口。首次切换会结束未完成对局；只要隧道连接仍存续，就不需要重新生成临时域名。全新部署可在原安装命令上加 `--live`，其余中继参数不变。

## 后续更新

先在本地开发和测试，通过后推送 GitHub，再在游戏服务器执行：

```bash
cd ~/tractor
git pull --ff-only
python3 tools/update_live.py
```

如果更新时允许结束所有牌局和 AI 计算，可使用 `python3 tools/update_live.py --reset-rooms`。公网入口和隧道不变，新后端从空房间注册表启动；玩家重新进入房间。已完成回放保留。这通常比迁移所有房间更快。

不执行 `systemctl restart`，也不重启隧道。安装器用于首次安装；日常更新用 `update_live.py`。非默认端口或运行目录须传入 `--port` / `--operations`。回放目录固定在工作仓库的 `runtime/history`，不会随版本目录切换。

更新程序将 `tractor_sim`、`web`、`rules`、`licenses` 及包元信息暂存到 `runtime/live/releases/<内容摘要>`，旧后端始终从自己的版本目录导入代码，不受工作仓库 `git pull` 影响。暂存目录只用于执行已测试版本，请勿手工编辑。运行时文件、SSH 配置、凭据、依赖和 Git 目录不会被打包。

网关暂停向后端转发新请求，排空原请求和正在计算的 AI，然后保存全部房间。状态包括牌堆、手牌、底牌、升级进度、随机数、座位与房主、托管设置、亮主轮询和计时、待结算确认、尚未完成的回放及各座位策略状态。排队的 AI 工作取消，已开始的 AI 计算完成后只保存策略状态，恢复时重新决策，避免应用旧异步结果。

新进程完成状态恢复、牌张守恒检查及健康检查后才切换流量。语法错误、启动失败、状态版本不兼容或超时会保留旧版并恢复计时；命令返回失败。可在 `runtime/live/workers.log` 和 `runtime/live/requests/*.result.json` 查看结果。同一内容重复更新不会替换进程。

## 使用范围

- 支持应用前后端更新；网关自身代码升级需要维护切换。协议或 checkpoint 结构不兼容的改动须编写迁移代码和兼容接口，否则会拒绝恢复。
- 当前保存 Enoch 与 Random 策略状态。新增有记忆的策略须适配 checkpoint，未适配的自定义策略会拒绝更新。
- 更新中机器断电、网关退出、旧进程崩溃、外网断线或 Cloudflare 隧道重新建链不属于本机制的不断连保证。网关重启仍会清空未完成牌局；完成回放持久保存。
- checkpoint 包含全部隐藏牌和登录凭据，仅用于服务器本地迁移。Linux 下运行目录权限 0700，JSON 权限 0600；Windows 应只给服务用户访问权限。没有公网更新接口，私有控制请求由回环地址和随机密钥保护，网关拒绝转发该路径。checkpoint 在更新结束后删除，所有运行状态由 `.gitignore` 排除。
