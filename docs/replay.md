# 历史对局与网页回放

从开局面板或顶部点击 **历史对局**，也可打开 `/history.html`。列表自动读取已保存的记录，无需选择文件；按日期分组、时间倒序排列，可以筛选玩法、打几，或搜索牌友、日期与房间号。结算弹窗的 **回放这一局** 直接进入本局记录。

历史页面在新标签页打开，原牌桌继续保持连接。手机和电脑均可使用。

## 播放操作

- **下一步 / 上一步**：一次移动一个已接受的动作，并暂停自动播放。
- **自动播放 / 暂停**：默认每秒一步，到最后一步自动停止，再点击可从头观看。
- **速度滑条**：0.2×～5×，以 0.01× 连续调节。0.2× 每 5 秒一步，1× 每秒一步，5× 每 0.2 秒一步；点 **1×** 恢复默认。
- **进度滑条 / 时间线条目**：跳至任意动作，包含亮主、加固、反主、扣底、反底、甩牌罚分与结算。
- **跳至出牌**：跳过摸牌、亮主和扣底，进入第一次出牌前的状态。
- **跟随行动 / 南西北东**：底部大手牌跟随当前步骤行动者，或固定查看某家；桌上始终展示四家手牌。
- 键盘 **← / →** 前后一步，**空格** 播放 / 暂停。切到后台标签页时自动暂停。

一步对应一次实际接受的动作，非法请求不计步。动作可能同时触发摸牌、收墩或结算，这些结果随该动作展示。第 0 步是首张牌已摸到的开局状态。恒定播放速度用于复盘，不复现玩家原本的思考等待时长。

打开一局时一次加载全部步骤，播放、跳转和变速都在浏览器内进行，不会向真实牌桌提交动作。

## 自动保存

网页的自对弈、PVE、PVP 都自动记录真人和策略实际执行的动作，**每局结算后** 写入服务器本地文件：

```text
runtime/history/打J_2026-10-11_22-32-58-123456_42a371f8.json
```

文件名包含本局级别、服务器结算日期与时间、避免重名的短 ID。一场升级比赛每局单独保存；无人抢庄导致的重洗仍保留在同一局记录内。

服务重启后重新索引文件，房间退出或过期不会删除记录。临时文件完整写入后才替换正式文件。保存失败不撤销结算，结算弹窗提示检查服务端存储。

可指定其他 D 盘目录：

```powershell
python -m tractor_sim --serve --headless --history-dir D:\Research\Tractor\Records
```

存储目录不作为静态资源下载，不包含在发布 ZIP 或 Git 中。记录仅结算时落盘；中途终止的局不发布，不支持意外退出后恢复未完成对局。

## 可见范围与格式

服务器历史页面是共享档案：访问者可查看已完成对局的四家历史手牌、名字和公开动作。当前没有账号或个人历史隔离。进行中的局不出现在历史接口，PVE/PVP 的即时手牌权限没有改变。

出牌前与出牌过程中隐藏底牌仍为 `null`，扣底动作仅显示“扣下八张”；只有无人亮主翻底定主时提前公开。结算步骤通过 `state.settlement_kitty` 展示最后一次实际扣下的八张底牌。旧记录会从最后一次完整扣底动作恢复最终底牌，不改动早期步骤。本地文件保留完整扣底动作供可信离线核对，不作为玩家或 AI 的即时观察。

记录保存各步实际状态快照，网页不重新调用策略，也不依赖未来规则重新执行。原 CLI `--output` / `--replay` 校验接口继续可用，其格式与网页快照不同。

## 已有评测记录

本机已导入上次完整 AI 评测的 32 局，标记 **AI 评测 / 评测导入**。导入先从种子执行全部未脱敏动作并比对结算。部分截图和观察不足以构造完整回放，因此此前手动 PVE 旧局不能补出。

评测导入日期来自原始完整记录文件的修改时间；当时未保存各局精确墙钟时间，列表时间不能视为各局真实结束时刻。新网页对局保存真实开始与结算时间。

本地操作工具（重复执行跳过已导入局）：

```powershell
python -m tools.import_history build/ai-evaluation.json
```

需使用未脱敏完整文件。公开的 `docs/ai-evaluation.json` 已脱敏扣底，不能用于重建。

## HTTP 接口

`GET /api/history` 返回 `{schema_version: 1, records: [...]}`，仅含完成局元数据，结算时间倒序。包含 `id`、`filename`、`mode`、`source`、`players`、`level`、`trump`、`round`、`steps`、`tricks`、`started_at`、`finished_at` 与 `result`。

`GET /api/history/<id>` 一次返回 `{schema_version: 1, meta: {...}, frames: [...]}`。每帧含 `actor`、`action`、`at_ms`、`events`、`state`；`state.hands` 是动作后的四家手牌。`at_ms` 是相对本局开始的实际记录时间，播放间隔由速度控制器决定。ID 不存在或不合法返回 404。

接口只读，无需入座 token，不提供写入、删除、任意路径读取或未完成局接口。实时 `/api/state` 新增 `replay_id` 与 `history_error`，用于结算回放入口与保存状态。
